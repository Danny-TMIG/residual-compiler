# Security Policy

## Reporting a Vulnerability

Open a private security advisory on this repository, or email the maintainer.
Do not open a public issue.

Response target: 72 hours. No public disclosure without coordination.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.3.x   | yes       |
| 1.2.x   | yes       |
| < 1.2   | no        |
